Bundled components
------------------

The Windows build ships several independent programs so that nothing has to be
installed or hunted for. They keep their own licences, and the most important
consequence is spelled out below.

FFmpeg -- GPL v3
    https://ffmpeg.org/
    The build included here is compiled with x264 and x265, both of which are
    GPL-licensed. That makes the FFmpeg binary GPL v3, and therefore makes the
    *distributed bundle* (installer or portable executable) subject to GPL v3
    terms as a whole, even though this project's own source remains MIT.

    In practice, if you redistribute the built application you must:
      - pass on these licence terms, and
      - make the corresponding source for FFmpeg available. The upstream
        sources are at https://ffmpeg.org/download.html and the exact build is
        identified in the application's About information.

    If you would rather not take on GPL obligations, build without FFmpeg. The
    application degrades gracefully: the video tab's metadata route keeps
    working (it is pure Python), and only the re-encode option disappears.

ExifTool -- Perl Artistic Licence / GPL v1+ (dual)
    https://exiftool.org/
    Copyright Phil Harvey. Redistributed unmodified.

DNGLab -- LGPL v2.1
    https://github.com/dnglab/dnglab
    Redistributed unmodified as a separate executable.

LibRaw (via rawpy) -- LGPL v2.1 / CDDL
    https://www.libraw.org/
    Used to develop raw files when a rendered JPEG is requested.

Qt / PyQt6 -- GPL v3 (open-source edition)
    https://www.qt.io/  |  https://riverbankcomputing.com/software/pyqt/
    The user interface toolkit. PyQt6's open-source edition is GPL v3, which is
    a second reason the distributed Windows bundle carries GPL terms.

Pillow -- MIT-CMU
    https://python-pillow.org/

Python -- PSF Licence
    https://www.python.org/
