Desqueeze -- licensing
======================

THE SHORT VERSION
-----------------
This project is licensed under the GNU General Public Licence, version 3.
The full text is in LICENSE at the root of the repository.

GPL v3 was chosen because it is the licence that lets this software be packaged
and distributed as a working product. The application bundles FFmpeg (built
with x264/x265) and PyQt6, both of which are GPL, and a bundle containing them
must be distributed under GPL terms. Adopting GPL v3 for the whole project
makes the installer and the portable executable straightforwardly
redistributable instead of being a licence conflict waiting to be noticed.

WHAT GPL v3 LETS YOU DO
-----------------------
  - Use the software for anything, including commercially.
  - Distribute it, free or for money.
  - Modify it and distribute your modified version.

WHAT IT ASKS IN RETURN
----------------------
  - Ship this licence and the copyright notice with any copy you distribute.
  - Make the corresponding source available to whoever receives a binary --
    a link to the public repository satisfies this.
  - Release your modifications under GPL v3 as well.

What it does NOT allow is taking this code into a closed-source product. If
that ever becomes the goal, the two GPL dependencies have to go: PyQt6 would be
replaced by PySide6 (LGPL v3) and the FFmpeg build by an LGPL one, which means
giving up the x264/x265 software encoders in favour of hardware encoders or
openh264/kvazaar. Nothing else in the project stands in the way.


BUNDLED COMPONENTS
------------------
The Windows build ships several independent programs so that nothing has to be
installed or hunted for. Each keeps its own licence.

FFmpeg -- GPL v3
    https://ffmpeg.org/
    Compiled with x264 and x265, which are GPL. Re-encoding uses this.
    Corresponding source: https://ffmpeg.org/download.html -- the exact build
    is identified in the application's startup log.

PyQt6 -- GPL v3 (open-source edition)
    https://riverbankcomputing.com/software/pyqt/
    The user interface toolkit.

Qt -- LGPL v3
    https://www.qt.io/

ExifTool -- Perl Artistic Licence / GPL v1 or later (dual)
    https://exiftool.org/
    Copyright Phil Harvey. Redistributed unmodified. Writes DefaultScale into
    every raw format, including Canon CR3 and Fujifilm RAF.

DNGLab -- LGPL v2.1
    https://github.com/dnglab/dnglab
    Redistributed unmodified. Converts proprietary raw to DNG.

LibRaw (via rawpy) -- LGPL v2.1 / CDDL
    https://www.libraw.org/
    Develops raw files when a rendered JPEG is requested.

Pillow -- MIT-CMU
    https://python-pillow.org/

Python -- PSF Licence
    https://www.python.org/


THE ANDROID BUILD
-----------------
The APK bundles neither FFmpeg nor PyQt6 -- it uses pure Python and the phone's
own codecs -- so nothing in it forces GPL. It is covered by this project's
GPL v3 for consistency, and could be released under a more permissive licence
if that were ever wanted.
